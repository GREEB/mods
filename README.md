# dirtytomat0 Deadlock mods

Download page: **https://greeb.github.io/mods/**

HUD Fit, 4:3 Video and Hero Select Plus for Deadlock. Install by dropping the zip into
Deadlock Mod Manager (Add Local Mod), or see the page for manual install.

AI was used to make these mods. Bugs and questions: open an issue.

The page is generated: `python3 build_site.py` copies the latest release zips and thumbnails
into `docs/` (served by GitHub Pages).
