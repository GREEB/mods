HUD Fit

Move, resize and de-stretch every HUD element, live in game.

Version 1.1 · 40 KB · source
Download HUD Fit 1.1
Details

Rearrange your HUD, live, in game

HUD Fit is an in-game editor for the Deadlock HUD: click any element, drag it, resize it, hide it. Built for 4:3 stretched players (de-stretch the HUD so it stops looking wide), useful on any resolution.

Open it: Esc → HUD Fit (under Settings). Best in Explore NYC or a sandbox / Hero Testing match — the hideout hides most of the HUD.

Features

  • Click, drag, resize any of 22 HUD elements on the real HUD — health bar, abilities, items & souls, weapon/spirit/vitality, minimap, top bar, crosshair & ammo, kill feed, chat, prompts, buffs, damage meter and more
  • Snapping to screen edges, the centre and other elements; W A S D nudge (Shift = 10 px), + / − size
  • Center buttons: put the crosshair or any element exactly in the middle of the screen
  • Layers panel: show/hide each element in game, lock it, reset it with one click
  • 4:3 stretch fix: de-stretch chosen elements or everything (4:3, 5:4, 16:10 presets)
  • Scale all items: make the whole HUD bigger or smaller — every element stays at its screen edge
  • Fixes the health bar disappearing at 4:3 (the stock layout only fits 16:9 and wider)
  • Test tab: one-click sandbox situations (damage, low health, death/respawn timer, level up, souls, buffs, enemy bot, trooper wave, DPS meter) so you see the real UI while arranging it
  • Layouts: Default, Clean and up to 20 named layouts — export / import a layout code to share it
  • Filters with a strength slider: Monochrome, Sepia, Neon, Ice, Ghost, Focus, Muted
  • Everything is saved on your PC and comes back after a restart

Install

  • Install with Deadlock Mod Manager, or copy the VPK into game/citadel/addons as the next free pakNN_dir.vpk
  • Made to be used together with 4:3 Video (adds a 4x3 aspect ratio option to the video settings)

Compatibility

  • Works with Hero Select Plus and 4:3 Video
  • Conflicts with other mods that replace base_hud or hud_escape_menu, and with full HUD overhauls
  • After a big game update, if the HUD looks wrong, disable the mod until an updated build is posted

Saving & privacy

Layouts are kept in your PC's game browser storage through a tiny page with no network access (nothing is uploaded): hudfit-storage.

Open source

Source and community filters: GitHub — new filters welcome as pull requests.

4:3 Video

Adds a 4x3 aspect ratio button to the video settings, without hiding new settings.

Version 2.0 · 4 KB
Download 4:3 Video 2.0
Details

A 4x3 button in the video settings

Adds a 4x3 choice to Settings → Video → Aspect Ratio, next to 16:9, 16:10 and 21:9. Pick it and the resolution list shows the 4:3 modes your graphics driver offers.

Why this one

  • Older 4:3 mods ship a whole copy of the settings screen — that hides every newer setting (Down Dash bind, shop binds, subtitle options…) and gets worse with every patch
  • 4:3 Video never replaces the settings screen: the button is added to the live screen while it is open, so settings from future game updates always show up
  • Remembers your choice: 4x3 stays selected when you reopen the settings

Higher 4:3 resolutions

Want 1920×1440 or similar? The game lists what your graphics driver offers — add them as custom resolutions first (AMD Adrenalin, NVIDIA Control Panel or CRU).

Install

  • Install with Deadlock Mod Manager, or copy the VPK into game/citadel/addons as the next free pakNN_dir.vpk
  • Turn off older 4:3 settings mods (they replace the settings screen)
  • Made to be used together with HUD Fit — de-stretch, move and resize the HUD for 4:3 stretched

Compatibility

  • Works with HUD Fit and Hero Select Plus
  • Changes only one tiny HUD file (subtitles layout); the settings screen is never touched

Hero Select Plus

Hero names, classes, search and filters on the hero select screen.

Version 1.0 · 19 KB
Download Hero Select Plus 1.0
Details

Learn the heroes faster

Hero Select Plus makes the hero select screen easier to read, especially if you are new to Deadlock.

Features

  • Hero names always visible on every card
  • Class on every card, colour coded: Marksman, Assassin, Mystic, Brawler
  • Search box: hero name, class, tag, weapon type or difficulty — several words narrow it down (e.g. brawler tank)
  • Class filter buttons plus a Beginner button for heroes the game recommends to new players
  • Hover details: class, difficulty, weapon type, a one-line role and the playstyle summary
All hero information is read from the game's own data when the mod is built.

Install

  • Install with Deadlock Mod Manager, or copy the VPK into game/citadel/addons as the next free pakNN_dir.vpk

Compatibility

  • Works with HUD Fit and 4:3 Video
  • Conflicts with other mods that replace the hero select popup or hero card layouts
  • After a game update, if hero select looks wrong, disable the mod until an updated build is posted

Install with Deadlock Mod Manager

  1. Download the mod's .zip above (don't unzip it).
  2. Open Deadlock Mod Manager and choose Add Local Mod.
  3. Drop the zip in, give it a name, add it, and turn it on.

Install by hand

  1. Unzip the download: it contains pak01_dir.vpk.
  2. Copy it to Steam/steamapps/common/Deadlock/game/citadel/addons and rename it to the next free number (pak01_dir.vpk, pak02_dir.vpk, ...; the game stops at the first missing number).
  3. The game only loads that folder once mods are enabled in gameinfo.gi; the Mod Manager does this for you.

Updating

Download the new zip from this page and add it again (remove the old one in the Mod Manager first).
